LOCAL IMPORT OPERATOR

Run an approved import

On the database computer, run .\.venv\Scripts\python.exe scripts/admin_import.py in the project terminal. Sign in with an Admin application account, review the four local archives, and type IMPORT to confirm. The helper checks current access and prevents overlapping imports; this page displays their recorded outcomes.

Imports refresh stored reference data and are intentional operations. A later failure can leave earlier stages committed. No file upload or import is started by opening this page.

THE IMPORT AUDIT TRAIL

Recorded attempts

Each row is one recorded import attempt. Read rows and inserted/updated entities are different units. Repeated imports can update existing records; summing these counters does not give current dataset size.
